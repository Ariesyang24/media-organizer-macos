# Windows 版素材整理工具

第一次使用只需解压项目并双击 `一键安装并启动.cmd`。程序会自动检查并安装运行环境、创建桌面和开始菜单快捷方式，然后启动软件。以后直接点击桌面的 `Media Organizer` 即可，不需要输入任何命令。

操作顺序：添加素材来源 → 添加成片排除目录 → 选择输出 → 扫描并预览 → 必要时修改地点 → 执行整理。

程序默认复制并保留原文件，使用 SHA-256 校验，临时文件校验成功后才写入正式文件；同名不同内容自动添加 `_2`、`_3`。每次整理生成 CSV 记录和失败日志。

Windows 不提供 macOS 的系统地理反查服务，因此本版不会联网把 GPS 坐标转换为城市。视频元数据无法读取时使用文件修改日期。
