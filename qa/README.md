# 当前版本质量检查

这个目录只放当前正式版本（v53）的回归检查，不参与软件启动。

## 检查项

- `test_v53_current_ui.py`：按钮、筛选、抽屉、状态切换、预览和响应式布局。
- `test_resumable_organizer_v53.py`：低内存批量整理、中断续传、跳过已完成文件和失败重试。
- `capture_v53_ui_audit.py`：生成完成态和设置抽屉截图，供人工检查。
- `artifacts/ui-audit/`：截图输出目录，可删除后重新生成。
- `legacy/`：旧版本测试和诊断脚本，仅作问题追溯，不参与正式启动。

## 运行方法

在工程根目录使用随软件提供的 Python 运行以上脚本。正式用户不需要执行这些文件。

## 整理原则

旧测试和旧版本入口暂时保持原位，因为其中一部分仍依赖工程根目录的导入路径。后续只有在正式入口改为单一版本、完成全量回归后，才能统一归档。
