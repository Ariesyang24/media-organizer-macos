# Media Organizer · Windows

面向大量照片与视频的 Windows 桌面整理工具。它把素材扫描、智能审核、分类、预览、批量调整和安全复制整理集中在同一个工作台中。

> 当前 Windows 版本位于 `windows` 分支；仓库的 `main` 分支保留原有 macOS 版本。

## Windows 版功能

- 文件夹拖放和多来源扫描
- WAITING、SCANNING、PAUSED、COMPLETED、FAILED 单一状态控制
- 自动通过、待确认、明显问题、文件异常审核队列
- 白底商品图保护，白底正常素材归入自动通过
- 照片、视频和文件异常筛选
- 缩略图文件夹浏览，点击打开原始高清素材
- 画质、曝光、重复照片和连拍识别
- 离线人脸检测与人物聚类
- 视频镜头、关键帧和画质分析
- 可选的离线场景识别（实验功能，默认关闭）
- 识别缓存：未变化的素材不会重复分析
- 按日期、地点、设备和素材类型整理
- 默认复制并保留原文件，使用 SHA-256 校验
- 低内存分批整理、失败记录和中断续传
- 重新执行时自动跳过已经成功整理的文件
- CSV 审核报告和整理记录

## 界面与操作

- 左侧集中显示审核队列、素材类型和自定义分类。
- 中间工作台提供筛选、批量审核、相似项分组、移动分类和执行整理。
- 右侧抽屉提供识别设置、批量操作和素材详情。
- 侧栏支持 220px 展开和 72px 收起，并适配 1280px、1536px 和 1920px 窗口。
- 照片与视频可直接预览，也可打开原文件或视频关键帧。

## 运行方法

### 第一次使用

1. 点击 GitHub 页面右上角的 `Code` → `Download ZIP`。
2. 解压下载的 ZIP 文件。
3. 双击 `一键安装并启动.cmd`。

安装程序会自动完成 Python 检查、运行组件安装、桌面快捷方式和开始菜单快捷方式创建，然后直接启动软件。无需输入命令。

### 以后使用

直接双击桌面的 `Media Organizer`，或在 Windows 开始菜单搜索 `Media Organizer`。

如果桌面快捷方式被删除，也可以双击 `启动素材整理工具.cmd`。软件不会上传用户素材；缓存、测试素材和本机路径配置均由 `.gitignore` 排除。仓库中保留程序运行需要的识别模型文件。

## 使用流程

添加素材 → 选择排除目录和输出位置 → 扫描并预览 → 点击分类文件夹查看缩略图 → 审核结果 → 执行整理。

场景识别对部分专业或电商素材可能不准确，因此默认关闭，可在识别页面手动选择开启。

## 安全说明

- 默认只复制，不移动或删除原素材。
- 复制时先写入临时文件，完成 SHA-256 校验后再写入正式文件。
- 测试素材、识别缓存、模型文件和本机路径不会上传到仓库。
