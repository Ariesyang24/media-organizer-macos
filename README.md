# Media Organizer

Media Organizer 是一款原生 macOS 摄影素材整理工具，用于安全扫描、预览和复制归类照片与视频。界面支持中文与 English，默认使用中文。

## 主要功能

- 递归扫描多个素材来源，并支持从 Finder 拖入文件夹
- 按日期、地点、设备、照片/视频及原始文件夹关系归类
- 从历史文件夹名称、照片 GPS 或手动批次设置解析地点
- 保留同一原始文件夹内照片与视频的对应编号
- 抽样识别稳定的延时摄影序列
- 执行前预览、排除成片目录、防覆盖和安全停止
- 默认复制并保留原文件，使用 SHA-256 校验复制结果
- 生成 CSV 整理记录及失败文件清单
- 可选照片文件重命名，默认关闭
- 支持中文或英文输出目录名称

## 系统要求

- macOS 13 或更高版本
- Apple Command Line Tools（用于首次编译 Swift 源码）

## 使用方法

1. 下载或克隆本仓库。
2. 双击 `启动素材整理工具.command`。
3. 添加一个或多个素材来源，并设置总素材文件夹。
4. 点击“扫描并预览”，确认目标结构。
5. 保持“复制并保留原文件”后执行整理。

首次运行时，启动脚本会使用 macOS 自带的 Swift 编译器生成本地应用和元数据读取组件。详细规则参见 [使用说明.md](使用说明.md)。

## 安全说明

- 不修改照片、视频或其 EXIF 元数据。
- 默认不移动或删除原素材。
- 复制时先写入临时文件，校验 SHA-256 后再放入正式路径。
- 单个异常文件不会阻塞整个批次。
- 建议首次使用时先选择少量素材测试并核对预览结果。

## 从源码构建

```bash
chmod +x "启动素材整理工具.command"
./启动素材整理工具.command
```
