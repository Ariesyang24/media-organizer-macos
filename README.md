# Media Organizer · Windows

这是 Media Organizer 的 Windows 版本，用于扫描、识别、预览和安全整理照片与视频。

## Windows 版功能

- 文件夹拖放和多来源扫描
- 照片、视频、失败项目分类
- 缩略图文件夹浏览，点击打开原始高清素材
- 画质、曝光、重复照片和连拍识别
- 离线人脸检测与人物聚类
- 视频镜头、关键帧和画质分析
- 可选的离线场景识别（实验功能，默认关闭）
- 识别缓存：未变化的素材不会重复分析
- 按日期、地点、设备和素材类型整理
- 默认复制并保留原文件，使用 SHA-256 校验
- CSV 审核报告和整理记录

## 运行方法

1. 安装 Python 3.11 或更高版本。
2. 安装依赖：

   ```powershell
   py -m pip install -r requirements-windows.txt
   ```

3. 双击 `启动素材整理工具.cmd`。

## 使用流程

添加素材 → 选择排除目录和输出位置 → 扫描并预览 → 点击分类文件夹查看缩略图 → 审核结果 → 执行整理。

场景识别对部分专业或电商素材可能不准确，因此默认关闭，可在识别页面手动选择开启。

## 安全说明

- 默认只复制，不移动或删除原素材。
- 复制时先写入临时文件，完成 SHA-256 校验后再写入正式文件。
- 测试素材、识别缓存、模型文件和本机路径不会上传到仓库。
